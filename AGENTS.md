This `rust` crate is a library of types used in the [`Chimithèque`](https://github.com/chimitheque/gochimitheque) application.

## Specific project instructions

- Each type has a corresponding `_tests.rs` file containing its unit tests.
- Some types implement the `Searchable` trait from `chimitheque_traits`. This trait simplifies database search operations for types containing only name and id fields.
- The `testdata` directory contains sample JSON files obtained from the PubChem online database. These files are used as test fixtures.
