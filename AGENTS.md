# AGENTS.md - Chimithèque Types Library Agent Guide

This `rust` crate is a library of types used in a chemical products, biological reagents and laboratory consumables management application.
Look at the `Cargo.toml` file to see the list of dependencies.
Each type as a `_tests.rs` file that contains unit tests for that type.
Some types implements the `Searchable` trait from `chimitheque_traits` that simplify the database search operations for types with only a `name` and `id` field.

The `testdata` directory contains sample JSON files from the PubChem online database.
